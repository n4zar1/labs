El pase de admin

Medio · ~12 min · Basado en el vídeo «Cambié una palabra en mi sesión… y era administrador (JWT manipulado)».

El caso. Tienda Example, una tienda online ficticia. Jueves 12/11 por la mañana alguien entró en el panel de administración, miró los datos de los clientes, cambió permisos y borró una cuenta. Nadie robó ninguna contraseña de administrador. Te pasan el token de sesión que la web le dio a la clienta Ana, el registro de la API, el código que lee el token y la línea de tiempo del SIEM.

Tu misión: descodifica el token, descubre qué cambiaron y cómo lo aceptó el servidor, desde dónde, qué hicieron y qué arreglo lo cierra. Chuleta: un JWT son tres trozos en Base64URL separados por puntos (cabecera, datos y firma). Codificar no es cifrar: cualquiera lo lee. Lo único que impide cambiarlo es que el servidor compruebe la firma.

3 · El servidor por dentro: cómo lee el token (Node, librería jsonwebtoken)

    
// middleware/sesion.js
const jwt = require('jsonwebtoken');

function sesion(req, res, next) {
  const token = req.cookies.sesion;
  const datos = jwt.decode(token);   // TODO: verificar la firma
  if (!datos) return res.status(401).end();
  req.usuario = datos.usuario;
  req.rol = datos.rol;                 // "user" o "admin"
  next();
}

// rutas/admin.js
router.use((req, res, next) => req.rol === 'admin' ? next() : res.status(403).end());
