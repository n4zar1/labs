Sube una carpeta

Medio · ~12 min · Basado en el vídeo «Tres caracteres… y la web me dio sus contraseñas (path traversal)».

El caso. Facturas Olmo, una empresa ficticia que deja a sus clientes descargar facturas en descargas.example/ver?archivo=factura.pdf. Viernes 6/11. Esta mañana alguien ha entrado en su base de datos con el usuario de la propia web, y nadie sabe de dónde sacó la contraseña. Te pasan el registro del servidor con lo que marcó su WAF (en modo «solo detectar»), cómo están las carpetas del servidor, el código que sirve los archivos y los accesos a la base de datos.

Tu misión: descubre quién salió de la carpeta de descargas, cómo se saltó el filtro, cuántas carpetas subió, qué archivo se llevó y qué arreglo lo cierra de verdad. Chuleta: en una ruta, ../ significa «la carpeta de arriba». Si la web pega lo que escribes a su carpeta sin comprobarlo, cada ../ te saca un piso. Eso es un path traversal (CWE-22).

1 · Registro del servidor + WAF (OWASP CRS, solo detecta) · 6/11, de 09:10 a 09:20

2 · Carpetas del servidor

/app/
├── config/
│   └── .env                 ← usuario y contraseña de la base de datos, contraseña del correo
└── web/
    └── estaticos/
        └── descargas/       ← la única carpeta que la web debería servir

            ├── contrato.pdf
            └── garantia.pdf

3 · El código que sirve los archivos (app.py)

DESCARGAS = "/app/web/estaticos/descargas/"

@app.get("/ver")
def ver():
    crudo = request.query_string.decode()     # la URL tal y como llega
    if "../" in crudo:                         # filtro casero
        return "Petición no válida", 400

    archivo = request.args["archivo"]          # aquí ya viene decodificado
    return send_file(DESCARGAS + archivo)

Bandera:

Lo que haría Facturas Olmo: cambiar ya la contraseña de la base de datos y la del correo (las del .env ya no son secretas) y cortar el acceso de 203.0.113.45; dejar de construir la ruta con lo que manda el usuario (lista blanca de archivos o ids) y, si no queda otra, normalizar la ruta y comprobar que sigue dentro de descargas/; quitar el filtro casero, que da falsa seguridad; que el usuario con el que corre la web no pueda leer config/; sacar los secretos de cualquier sitio que la web pueda servir; poner el WAF en modo bloqueo y alertar cuando una regla 930xxx coincida con un 200; y, como se ha leído la tabla de clientes, valorar con su delegado de protección de datos si toca notificar la brecha.
